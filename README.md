# Firm Finder

Firm Finder is a prototype tool that finds law firms in a specified city or region. It scans listings and firm websites to collect public contact details such as phone numbers, emails, and the practitioners who work there.

A demo video showing how the application works is available in the `demo/` folder (`demo/Firm_Finder_product_film.mp4`). Note that all firm names and contact details shown in the video are placeholders.

### How to run it

1. Install Python 3.10 or newer.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```
3. Start the application:
   ```bash
   python run.py
   ```
4. Open `http://localhost:8000` in your browser.

No API keys or paid external accounts are required to run the local prototype.
